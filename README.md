# Граф денег — роли и приоритеты финансовой сети

Локальная платформа расследования переводов: загрузка **CSV / Parquet / XLSX**, подтверждение колонок, проверка качества, объяснимые роли, граф связей, симуляция блокировки и печатное досье.

![Расследование](money_graph/docs/screens/investigate.png)

## Возможности

- Проекты с загрузкой CSV, Parquet и XLSX, сопоставлением колонок и проверкой качества.
- Объяснимые роли узлов, приоритеты, кластеры и трассировка сработавших правил.
- Интерактивный граф: формы и пиктограммы, поиск, раскрытие соседей, фильтры и временная шкала.
- Симуляция блокировки узлов с сопоставлением со случайным выбором и диаграммами потоков.
- Таблица с экспортом выбранных строк, дела аналитика и HTML-досье для печати в PDF.
- Ассистент из репозитория: локальные инструменты и опциональные вопросы в OpenAI.
- Русский, английский и казахский интерфейс, светлая и тёмная темы.

## Быстрый запуск

Python 3.10+; Node.js для запуска готового приложения не нужен.

```powershell
git clone --branch main https://github.com/BAITC-Hacks/hack-61c5ca4c-orbit-digital-ako.git
cd hack-61c5ca4c-orbit-digital-ako
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r money_graph/requirements.txt
.\.venv\Scripts\python.exe money_graph/serve.py
```

Если репозиторий уже скачан и зависимости установлены:

```powershell
cd money_graph
python serve.py
```

Откройте **http://127.0.0.1:8000** → «Открыть пример» или «Новый анализ».

API: **http://127.0.0.1:8000/api/docs** — документация также доступна офлайн.

Готовая сборка фронтенда находится в `money_graph/web/dist/`. Для изменения интерфейса нужен Node.js 20.19+ или 22.12+:

```powershell
cd money_graph/web
npm ci
npm run build
```

## Ассистент

Локальные действия работают без API-ключа. Чтобы включить вопросы на естественном языке, из папки `money_graph` установите `requirements-ai.txt`, создайте `.env` по `.env.example`, задайте `OPENAI_API_KEY` и перезапустите сервер. Для каждого внешнего запроса интерфейс запрашивает подтверждение отправки данных. Ключ не вводится в браузере и не хранится в Git.

## Расчёт по ТЗ хакатона

```powershell
cd money_graph
python run.py
python check.py
```

CLI и веб-приложение используют одно ядро `mg.pipeline.run_pipeline`. Эталон сохранён: 2 248 узлов, 71 кластер, поток 253 083 784, AUC 0,66; распределение ролей и топ-3 совпадают.

## Проверки и границы MVP

В контрольном прогоне прошли **80 Python-тестов**, **4 Playwright-сценария**, `run.py`, `check.py` и сборка фронтенда. На синтетике из 100 000 узлов и 300 000 транзакций полный расчёт занял **245,7 с** на машине разработки. Условия измерений и ограничения приведены в отчёте ниже.

Приложение рассчитано на локальную работу одного аналитика. Для общего сетевого доступа нужны аутентификация, разграничение прав и защищённое хранение. Реальный запрос к OpenAI не проверялся без настроенного ключа.

В `main` опубликован универсальный MVP с сохранённым эталоном ТЗ и выборочно интегрированным ассистентом из коммита `ab08d0d`. История обеих веток сохранена merge-коммитом; рабочая версия соответствует текущему MVP. Хронологическая модель и личные кабинеты из прежней версии `main` доступны в истории (`ab08d0d`) и требуют отдельной функциональной интеграции.
